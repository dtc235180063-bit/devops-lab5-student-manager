- Main Branch         : Chứa mã nguồn ổn định nhất (Production Ready), phiên bản v1.0.0
- Develop Branch      : Nhánh tích hợp các tính năng chuẩn bị cho bản phát hành

  + PR #2: develop <- feature/search-student (Dev A review, đánh giá chất lượng & approve; Merged)
- Merge Conflict Simulation & Resolution :
  + Tạo conflict tại dòng 3 của file README.md giữa 2 nhánh `feature/update-readme-a` và `feature/update-readme-b`
  + Xuất hiện conflict markers (`<<<<<<< HEAD`, `=======`, `>>>>>>>`)
  + Xử lý xung đột đồng thuận tích hợp nội dung Nhóm A & Nhóm B
  + Commit merge `merge: resolve README conflict — combine Team A & B`
- Release & Merge to Main :
  + Merge nhánh develop vào main
  + Cập nhật README.md hoàn chỉnh
  + Kết quả kiểm thử tự động với verify.sh và verify.ps1 đạt 12/12 PASS (100%)
